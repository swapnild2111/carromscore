# Contact

Bug reports, feature ideas, "hey I use this at my club", tournament
questions — all welcome. Three ways to get in touch:

## Email

**swapnild2111 [at] gmail [dot] com** — for anything that doesn't fit
a public thread, or if you just prefer email.

Include what version you're on (visible in the app's footer, e.g.
`v1.8.0`) and roughly what happened. Screenshots help when something
looked wrong on-screen.

Or click the **Feedback ⇗** link in the app's setup screen footer —
that opens your default mail app with the version pre-filled in the
subject line.

## GitHub Discussions

**[Start a new thread](https://github.com/swapnild2111/carromscore/discussions/new?category=general)**
or browse existing ones at
**https://github.com/swapnild2111/carromscore/discussions**.

Public forum for feature ideas, questions, and general chat. Anyone
with a GitHub account can start a thread. Softer feel than Issues —
"here's an idea" or "how do I do X?" is welcome, no template.

## GitHub Issues

**https://github.com/swapnild2111/carromscore/issues**

For confirmed bugs and specific feature requests where you want
progress tracked. Requires a GitHub account. If unsure whether
something is a bug, email me or start a Discussion first — it can
always become an Issue later.

## Response time

Carromscore is a hobby project maintained in evenings and weekends.
Realistic response time is 1–3 days for email, similar for
Discussions. Serious bugs (app broken, data lost) get fastest
attention.
