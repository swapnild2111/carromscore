# Carromscore v2.1.1

Patch release. Fixes overlay legibility issues that streamers reported
after v2.1.0 shipped: on a Prism Live stream, the practice overlay's
digits were too small to read on a phone-sized viewer window, and the
Prism watermark in the bottom-right corner overlapped the last board
and TOTAL cells.

## Fixes

- **Practice overlay digits are now ~3x larger.** Board cells scale
  to `clamp(3rem, 8vw, 6rem)` — roughly 150 px on a 1080p canvas.
  TOTAL rides slightly bigger so the grand-total dominates the strip.
- **Right safe-zone for stream-software watermarks.** The overlay now
  reserves ~12 rem (~192 px on 1080p) of right padding so the Prism
  Live / OBS / YouTube stamp in the bottom-right corner no longer
  obscures the TOTAL cell or the last board. On mobile viewers this
  shrinks to 4 rem to preserve strip real estate.
- **Tiles are now 92 % opaque with a stronger backdrop-blur.** Was
  75 %, which let carrom-table wood grain bleed through and killed
  digit contrast on some feeds. Now reads on any camera background.
- **Hard black text-shadow around every overlay digit.** Belt-and-
  braces — even if the tile background is defeated by an unusually
  bright feed, the digit outline is unambiguous.
- **Practice-overlay header pill and cells now share the same tint,
  border, and padding.** Was inconsistent between the header and
  the score rows — cells looked thinner than the pill above them.

## Migration notes

- **No code-model changes.** All v2.1.x records continue to render
  unchanged. No RTDB rule updates. Existing archives on production
  work without republishing rules.
- **APK upgrade optional.** Over-the-top APK upgrade works via the
  usual TWA path. Existing v2.1.0 APK users pick up the overlay CSS
  automatically on next open — no forced APK reinstall needed.
