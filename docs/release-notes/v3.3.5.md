# Carromscore v3.3.5

Round tag rides onto live matches. The Now Playing tab groups
matches two levels deep (tournament → round → match), matching
the pattern History has had since v3.2.

**APK SHA-256**: `f3a91f2b831c22649232c0d791896cfcc736ffa9ca49a4656922556380f0b0f9`

<!-- apk-required: false -->

Web changes only — existing v3.3.4 APK installs auto-update on
next launch.

## What changed

- **Round travels with live matches.** `/live/{mid}/meta` now
  carries the round + roundKey pair when the umpire tags a match
  with a round at setup. v3.2 deliberately skipped this for
  scope; the live path was the last one silently dropping the
  round tag.
- **Now Playing groups by round.** Every tournament group in the
  Now Playing tab gets round sub-headers with their own caret +
  count + collapse. Matches without a round tag land under an
  italicised *Unassigned* tail. Ghost rounds (round record
  deleted but match still tagged) render under their own
  sub-header alphabetically after the known rounds. Tournaments
  with no rounds roster fall through to the pre-v3.3.5 flat
  card list — same *round-flat* short-circuit the History tab
  uses.
- **Popup header shows the round for live matches too.**
  v3.3.4 shipped the round tag on the popup header for archived
  matches. Now the LIVE-source popup reads its round from
  `/live/{mid}/meta.round` too, so the "Ended · Singles · …"
  line reads the same for a match mid-play and after it ends.
- **Round chip on the card body was removed.** Once the card
  sits under a round sub-header, echoing the name on the card
  itself was duplicate ink.

## Migration notes

- **No breaking changes.** `/live/{mid}/meta` allows arbitrary
  children per RTDB rule — no rule change needed. Match records
  written under v3.3.4 or earlier don't carry a live-side round
  tag; they'll show under *Unassigned* until republished.
- **APK bump** (versionCode 45 → 46, versionName 3.3.4 → 3.3.5)
  for TWA parity; wrapper otherwise unchanged.
