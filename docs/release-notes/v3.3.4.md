# Carromscore v3.3.4

Tiny patch: the match-detail popup now shows the round tag next to
the tournament in its header. Before: **Ended · Singles · 3rd
Singles Ranking Carrom Tournament 2026**. After: **… · League Round
Group A** appended when the archive carries a round.

Web changes only — existing v3.3.3 APK installs auto-update on
next launch.

## What changed

- **Popup header shows round.** `popupRound` derived in
  `LiveLobby.svelte` reads the archived match record's `round`
  field and, when present, appends it after the tournament in
  the popup header. Live entries don't carry a round on the
  `/live/{mid}` payload (v3.2 design decision), so this only
  appears for ended matches.
- **Subtler colour** on the round span so the tournament stays
  visually primary.

## Migration notes

- **No breaking changes.** Reads existing `round` field on
  match records — no schema change.
- **APK bump** (versionCode 44 → 45, versionName 3.3.3 → 3.3.4)
  for TWA parity; wrapper otherwise unchanged.
