# Carromscore v3.5.4

Patch release. Widens the edit-pencil scope so match creators see
it for their own records — not only tournament organisers.

**APK SHA-256**: `44833f03381939bc52eb9409348986f1f751d40be224d1a52f3b5b548014fab1`

<!-- apk-required: false -->

Web changes only — existing v3.5.3 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Creator can edit their own match**, regardless of tournament
  tag. Previously `canEditMatch` returned true only for super
  admins or the organiser of the record's tournament. If you
  recorded a match with no tournament tag (or under a tournament
  someone else owns), the pencil was hidden even though the
  self-delete button was visible in the popup. Fix: add a
  creator-path branch — if `record.createdBy === myUid` the
  pencil shows and Edit Modal opens normally.
- **RTDB rule widened** to match. `/matches/$matchId` update
  branch now permits writes when `data.createdBy === auth.uid`
  AND the tournament / tournamentKey / createdBy fields stay
  unchanged. Creators can fix scores on their own records
  without needing to be a tournament organiser or super. They
  can't re-tag to a different tournament (that path still
  requires the target tournament's organiser or super) and
  can't spoof another creator.

## Migration notes

- **RTDB rule update** required — `database.rules.json` needs a
  manual publish in Firebase Console before creator-only edits
  will land. Until you publish, the pencil renders but Save will
  return permission_denied for creator-not-organiser cases.
- **No schema changes.**
- **APK bump** (versionCode 63 → 64, versionName 3.5.3 → 3.5.4)
  for TWA parity.
