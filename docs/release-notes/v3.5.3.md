# Carromscore v3.5.3

Patch release. Follow-up to v3.5.2: the edit-pencil / self-delete
gates now hydrate reactively after sign-in, so organisers and match
creators see the affordances without needing a manual reload.

**APK SHA-256**: `e52dddb3c59ac67405b4d4aa7a3918d192194186bc2cfdaa3347b0be1b10520d`

<!-- apk-required: false -->

Web changes only — existing v3.5.2 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Reactive auth uid inside LiveLobby.** Previously
  `canEditMatch()` and the popup's `owns` check called
  `currentUser()` synchronously at template render — the return
  wasn't reactive, so a slow auth hydration left the checks
  stuck at "not signed in" even after the user's uid actually
  landed. Reported 2026-08-30: an organiser saw History rows
  render but no ✎ pencil (super admin saw pencils fine, since
  the super check runs before the uid check). Fix: subscribe to
  auth on mount and store the uid as `$state`; `canEditMatch`
  and the popup's ownership check both read it reactively so
  they re-evaluate the moment auth hydrates.
- **`tournamentTick` touched in canEditMatch** too, so the
  pencil appears the moment the tournaments store hydrates
  (was already covered for other deriveds).
