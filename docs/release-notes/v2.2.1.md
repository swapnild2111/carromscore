# Carromscore v2.2.1

Patch release. Two small tweaks that landed together.

## Fixes

- **Practice records in the `/admin/` History cleanup tab now show
  real MISSES + BOARDS.** They were stuck at `0-0 · 0-0` because the
  admin row summary reads `finalPointsA` / `finalPointsB` on the
  match record — fields practice records populate with 0. The Lobby
  History card was fixed for the same reason in v2.1.2; this patch
  applies the parallel fix to `AdminHistoryCleanup.svelte`. Now
  practice rows read like `13 misses · 8 boards`, computed the same
  way the Lobby card computes them (sum of the `practiceBoards`
  matrix).

## Polish

- **Admin panel gains the same footer as home and lobby.** How to use
  ⇗ · Feedback ⇗ · Admin, then version + copyright. Version pill
  links to the release notes on GitHub, matching every other screen.
- **Header no longer shows the signed-in avatar twice.** The
  admin-panel header had a `<SignInButton signedInOnly />` chip that
  duplicated the auth entry now sitting in the footer. Header is
  now just Back + title; auth entry lives once, in the footer,
  everywhere in the app.

## Migration notes

- **No RTDB rule changes.** Existing rules keep working.
- **No breaking changes.** Every v2.2.0 record renders unchanged.
  Existing practice records in the admin panel start reading
  correctly immediately.
