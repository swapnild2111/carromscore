# Carromscore v2.2.3

Patch release. Two small fixes.

## Fixes

- **Player summary table now scrolls horizontally on narrow phones.**
  Long player names in the first column pushed the Boards / Points
  columns off-screen with no way to see them. Wrapped the table in a
  horizontally-scrollable div with a `min-width` so all seven
  columns stay reachable on any width. Same pattern the Matches
  table below already used.
- **Firebase reconnect nudge on visibility return.** When the score
  screen becomes visible again after being hidden for more than two
  seconds (screen unlock, app-switch back, etc.), the app now
  force-cycles the RTDB connection via `goOffline()` + `goOnline()`.
  On healthy connections this is a no-op — the SDK reconnects
  instantly. On aggressive-throttling Android devices (Xiaomi /
  Poco / other MIUI) where the OS suspends the WebSocket without
  the SDK noticing, this abandons the stuck connection and forces
  a fresh handshake, cutting recovery time from 3-10 seconds to
  under one. Only fires after real background transitions, so quick
  focus-blur flickers (notification pull-down, Chrome popup) don't
  trigger it.

## Migration notes

- **No RTDB rule changes.**
- **No breaking changes.** Existing records unaffected.
