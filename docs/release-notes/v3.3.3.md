# Carromscore v3.3.3

Patch release. Two threads:

1. **Reports tab overhaul** — summary tiles, a round filter, and
   a proper leaderboard treatment inspired by
   [carrom-thane.web.app](https://carrom-thane.web.app/). Per-round
   Copy button. Download CSV dropped.
2. **Admin polish** — INVITE-ONLY / OPEN chips replace the
   confusing CLOSED label; tournament row updates reflect edits
   without a refresh; DB keys / ids / mid slugs no longer leak
   into admin rows.

## Reports tab

- **Summary tiles** — Matches / Players / Boards / Leader show
  above the charts. One glance answers "what am I looking at."
  Leader tile gets an accent tint; ties for first read "Tied".
- **Round filter** — chip strip below the tournament picker,
  visible only when the tournament has rounds. Scopes the
  summary tiles, charts, leaderboard, and matches table to a
  single round. All rounds is the default. The per-round
  breakdown accordion hides when a specific round is filtered
  (would be redundant).
- **Leaderboard** — the "Player summary" table gains a rank
  column with ties rendered as "—" so groups read cleanly. Top
  row gets an accent tint. Applied to the combined view and
  every per-round accordion.
- **Per-round Copy table** — every accordion body has its own
  Copy button; the "Copied" flash is keyed per round, so one
  button lighting up no longer implies the others.
- **Download CSV removed** — Copy table is the paste-into-any-
  spreadsheet flow, and downloading a file mid-tournament was
  noise.
- **Bar-chart label clipping fixed** — long player names
  ("Yuvaraj Eshwaramoorthy") used to have their first letter
  clipped against the SVG's left edge. Layout switched to
  label-above-the-bar, which reads better on phones too.
- **"Default" tournament** chip moved to the tail of the picker
  strip and de-emphasised (italic, muted). Real events lead.
- **Chart subtitles hide when vacuous** — "Draws not counted"
  only shows if a draw actually happened in the data.

## Admin — Tournaments tab

- **INVITE-ONLY / OPEN chips** replace the "CLOSED" label. The
  old label read as "the event is over" when the actual meaning
  was "restricted-entry event with an assigned roster." Rename
  applied everywhere: row chip, Edit dialog radio, Add dialog
  copy + radio, home-form warning. **Data model unchanged** —
  RTDB still stores `type: 'open' | 'closed'`.
- **Both chips render** — previously only closed rows carried a
  chip; the OPEN/INVITE-ONLY pair now scans at a glance across
  the whole list. Chips share a shape (uppercase, letter-
  spaced), colour splits them (accent yellow vs neutral).
- **Reactive edit updates** — toggling access via the Edit
  dialog reflects on the row immediately, no refresh needed.
  `saveEdit` now bumps the reactive tick explicitly after every
  successful save so an in-place mutation of the memoryStore
  entry can't miss Svelte's dependency graph.

## Admin — DB-key surface removed

The `key: test-denmark` / `id: swapnil-...` / `mid <slug>` chips
were developer noise. Dropped from AdminTournaments rows, the
Rounds sub-modal, AdminPlayers rows, and AdminLiveCleanup meta.
Names + country + last-active are enough. The Live tab keeps
its "by <name/uid>" attribution.

## Migration notes

- **No breaking changes.** Data model unchanged; every rename
  ("CLOSED" → "INVITE-ONLY") is a display-only relabel.
- **APK bump** (versionCode 43 → 44, versionName 3.3.2 → 3.3.3)
  for TWA parity; wrapper otherwise unchanged.
