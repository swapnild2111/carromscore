# Carromscore v3.4.5

A grab-bag overlay polish release: country flags for every mode,
edge-to-edge strip with proper outer inset, silver-medal bug fix,
plus a few ScoreBoard header regressions from v3.4.2 undone.

next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

### Overlay — country flag on every pill

- **`countryA` / `countryB` now ride on the RTDB `/live/{mid}`
  payload** as ISO codes (e.g. `DK`, `IN`), independent of
  `noteA` / `noteB` (which double as round tags like "Tie Breaker
  1"). Remote `/live/?view=overlay` viewers now see the flag from
  the umpire's local Player record; older records without the
  field still fall back to parsing `noteA` for a country-shaped
  string.
- **ScoreBoard publishes country on every mode** (was singles-only
  in `MatchSetup.saveMatchIdentity`, meaning practice + doubles
  never carried a country to Firebase). Solo umpires now see
  their flag in the overlay + on their own header pill.
- **Practice ScoreBoard header renders a flag** next to the name
  — the JSX pattern the versus branch already had was missing on
  the practice branch.
- **URL override `?countryA=DK&countryB=IN`** on `/score/`
  routes for testing / sharing without depending on a local
  Player DB.
- **Fallback in overlay**: `flagEmoji(country || note)` — legacy
  records where `noteA` was a country name ("Denmark") still
  render a flag when `countryA` is absent.

### Overlay — layout

- **Silver-medal-on-fresh-match bug fixed.** Firebase RTDB strips
  explicit `null` before write; on read the field is
  `undefined`, which was slipping past the `matchResult !==
  null` gate and painting fresh matches with the winner treatment
  ("silver background from start"). Coerce undefined → null in
  `applyRecord`.
- **Edge-to-edge overlay strip** with balanced outer inset:
  `padding: 1.4rem clamp(3rem, 8vw, 8rem)` (was flush 0). The
  inner `gap` between digit and SET/BOARD middle column drops to
  `clamp(0.15rem, 0.35vw, 0.4rem)` — digit sits adjacent to
  middle, pills sit visually inset from viewport edges. Grid
  changed from `1fr auto 1fr` to `auto 1fr auto` so team cells
  hug their content.
- **`.overlay-wrap` `:global` overrides deleted from LiveLobby.**
  These were LiveScoreboardView-era tuning that clobbered
  OverlayBoard's `.digit` clamp to `1.4rem-2.4rem` on `/live/`,
  shrinking singles/doubles digits to a fraction of their
  intended size.
- **Per-team SETS chip removed** from the singles/doubles
  overlay. The middle set-pips strip + "SET 2nd" caption already
  encode set count; the per-side chip was a redundant third
  encoding.
- **Country flag position**: always before the name in every
  pill (was after the name on side B, appearing below on the
  flex-column pill).
- **Full name in solo pill** (has its own row, plenty of width);
  singles/doubles stay first-name-only (pill competes with digit
  for horizontal budget).

### ScoreBoard header

- **Singles / doubles head-side pills reverted** from
  `justify-self: stretch` (v3.4.2) to `start / end`. Pills hug
  their content and anchor at the outer corners; middle
  SINGLE-SET / BOARD column no longer squeezed by a short-name
  pill spanning half the strip.
- **Solo practice-head** pill overridden to `flex: 0 0 auto`
  with a `max-width` cap so it hugs the player name. PRACTICE
  meta + TOTAL MISSED sit centred next to it as one
  visually-grouped header.

## Migration notes

- **No RTDB rule changes.** `countryA` / `countryB` on
  `liveState.meta` are new optional string fields; existing
  rules already allow any string under `meta`.
- **No schema changes** for `/matches`, `/tournaments`, etc.
- **APK bump** (versionCode 52 → 53, versionName 3.4.4 → 3.4.5)
  for TWA parity; wrapper otherwise unchanged.
- **Older `/live/` records without `countryA`** will still show
  no flag until their umpire republishes (touches any state on
  the phone with v3.4.5 loaded). No backfill for stale records.
