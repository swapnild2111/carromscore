# Carromscore v3.4.8

Small footer + help-page tidy: merge two footer links into one,
put the feedback affordance where users actually look for it.

**APK SHA-256**: `cb17de488c3fb87782ad2221d5132ce95cd5df945436426fb434ab46f18170fa`

<!-- apk-required: false -->

Web changes only — existing v3.4.7 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Footer merged**: the separate "How to use ⇗" and "Feedback ⇗"
  links across the home, admin, and lobby footers are now a single
  **"Help ⇗"** entry. Reduces footer clutter without losing either
  affordance — the /help/ page carries the feedback dialog inline.
- **/help/ page — Feedback trigger at top-right**, paired with the
  ← Home back-link. Painted in the app's accent gold so it reads
  as the primary "reach the maintainer" affordance rather than a
  neutral link.
- **First-paint fix**: the Feedback anchor is now server-rendered
  by Astro so it appears immediately when the page loads. The
  previous Svelte-only mount produced a visible flash where the
  button popped in a beat after the rest of the page.
- **Repository housekeeping**: `docs/plan/` is now gitignored so
  local planning documents (business plans, technical roadmaps,
  Play Store launch notes) stay off the public repo.

## Migration notes

- **No RTDB rule changes**, no schema changes.
- **APK bump** (versionCode 55 → 56, versionName 3.4.7 → 3.4.8)
  for TWA parity; wrapper otherwise unchanged.

  in-app deep-links continue to work.
