# Carromscore v2.2.5

Broadcast overlay tune-up for practice mode. The scoreboard strip
now reads at proper broadcast-scale over a camera feed. No functional
changes to scoring or gameplay.

## Changed

- **Practice overlay: bigger digits.** The set-tile digits and TOTAL
  cell now scale roughly +50-60% over the previous sizing so the
  overlay dominates the frame on a broadcast the way it should. On
  a 1920px stream the set digits land at ~240px (was ~154px) and
  the TOTAL at ~260px. Floors bumped for phone-sized preview
  windows too — no more squinting during setup.
- **Practice overlay: bigger SOLO pill.** Player name, SOLO badge,
  and country label all scale up proportionally so the header row
  keeps its weight against the enlarged digit cells.
- **Practice overlay: SET label centered.** The `SET 1` / `SET 2` /
  ... labels now sit centered in their column both vertically and
  horizontally against the taller digit tiles, instead of reading
  offset next to the enlarged cells.

## Behind the scenes

- **Beta preview channel restored.** Pushes to a floating `beta`
  branch now publish to https://swapnild2111.github.io/carromscore/beta/
  as a public preview URL. Used to test overlay CSS on a real
  Prism / OBS browser source before landing on production. Docs
  in `.github/workflows/deploy.yml`.

## Migration notes

- **No RTDB rule changes.**
- **No breaking changes.** Overlay URLs (`?view=overlay&mid=<mid>`)
  keep working exactly as before — the cells just render bigger.
- Existing installed APKs will pick up the CSS via the next PWA
  fetch cycle. No action needed.
