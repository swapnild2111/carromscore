# Carromscore v3.8.0

Organiser profile system, print footer with logo on every page, and
mobile admin scroll fix.

**APK SHA-256**: `833f811ab7b38d41e59a9c78f05b1fdb05d5b07563eb68a11278fb65dc62c30a`

<!-- apk-required: false -->

Web changes only — existing v3.7.0 APK installs auto-update on
next launch.

## Organiser profile

New **Profile** tab in the Admin panel (first tab, default landing
for all roles on sign-in). Organisers enter their identity once and
it flows automatically to every tournament print — no re-entry per
tournament.

Fields: Your name · Organisation / federation · Address ·
Phone · Email · Website · Instagram · Facebook · YouTube · X ·
Logo (up to 2 MB, stored as base64 in RTDB).

Logo and "Organised by" are sourced from this profile for all print
covers and footers. Legacy per-tournament logo and organizer name
fields are kept as a fallback for tournaments created before the
profile system existed.

## Print — logo and footer on every page

Both the **tournament bracket** print and the **reports** print now
show a footer on every printed page with the organiser logo and
"Organised by …" text.

- Footer is in-flow (not `position:fixed`) so it renders correctly
  in Chrome's Save as PDF output.
- Bracket cover page: logo top-right in the header, footer at the
  bottom.
- Board QR sticker page and per-match QR pages: footer at the
  bottom of each page.
- Reports: footer at the bottom of the printed output.

## Bug fixes

- **Print footer not appearing in PDF**: `position:fixed` is
  ignored by Chrome when printing to PDF. Switched to in-flow
  `margin-top: auto` footer inside each flex-column `.page` section.
- **Logo/organizer missing on public print pages**: the
  `organiserProfiles/{uid}` RTDB rule required `auth.uid == $uid`,
  silently denying reads on the public print-bracket page. Changed
  to public read — the profile contains only display-name and logo,
  no sensitive data.
- **Admin panel footer overlap on Profile tab**: added
  `admin-tab-scrollself` class so the profile content scrolls
  within the fixed-height admin shell, matching the pattern other
  tabs use.
- **Mobile Add tournament dialog**: dialog scroll fixed so the form
  is reachable on small screens.

## RTDB rules

- `/organiserProfiles/{uid}`: read changed to `true` (public) so
  print pages can load the organiser logo without authentication.
- `/organiserProfiles/{uid}`: `contact` field replaced with `phone`
  (≤ 40 chars) and `email` (≤ 128 chars).

Publish the updated `database.rules.json` in Firebase Console.

## Migration notes

- **RTDB rule publish required** — see above.
- **No data migration** — existing tournaments continue to work;
  logo and organizer name fall back to per-tournament fields until
  the organiser saves their profile.
- **Web-only release** — no APK bump needed.
