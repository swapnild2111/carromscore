# Carromscore v2.1.0

A quality-of-life release built on top of v2.0's admin foundation.
Three user-visible features + a handful of fixes surfaced from real
club use.

## What's new

### Self-delete for signed-in users

Signed in with Google? Any match you recorded is now yours to remove.
Open the /live/ lobby → History tab → tap your match card → the
sheet shows a small "🗑 Delete this match" button at the bottom.
Type DELETE to confirm; the record disappears from Firebase and
from every spectator's lobby.

Editing your own scores still goes through an organiser — this is
delete-only. Tournament integrity trumps convenience.

Matches recorded anonymously (or before the sign-in) don't carry
ownership metadata and can't be self-deleted. Ask an admin.

### Draw match on End

The **End** button no longer freezes when sets and points are both
level. Tap End on a genuine tie and the match archives as a **DRAW**:

- Both pills get a warm bronze treatment with a 🤝 handshake medal.
- The winner dialog reads "DRAW · Match tied · sets 1–1 · points 5–5"
  with no fireworks (calm, not celebratory).
- Both sides get the decider set credited, so the header shows
  `SETS 1–1` — the set actually was played, it just ended level.
- Broadcast overlay + spectator URL mirror the treatment.

Previously the End button was disabled on a tie, and umpires had to
fake a point to unstick it. That's fixed.

### "Recorded by" attribution on match cards

Every match sheet now shows a small **Recorded by [Name]** line
above the delete area. The name comes from the signed-in user's
Google profile at match-end time; anonymous matches show nothing.

Historical records keep the write-time name — a later profile
rename doesn't rewrite past matches, which is the correct archive
semantic. No email or UID is ever shown publicly.

### /admin/ — Live matches (was Live cleanup)

The admin tab has been reworked into a **Live matches** view. Filter
chips at the top let you narrow to:
- **All** — every /live/ record (active + stuck), default view
- **Stuck only** — the old "no updates in >4 h, or >2 h without a
  matchResult" filter, retained as a shortcut

Each row is tagged either **LIVE** (recent activity) or **stuck**
so admins can distinguish at a glance. Multi-select + bulk delete
works on the current filter. Deleting only removes the ephemeral
/live/ slot — archived /matches records live under History cleanup.

### Practice mode polish

- **All boards inline.** The score screen for a solo practice run
  now renders every board of the current set in one row. No more
  B1–4 / B5–8 chip navigator. Sets remain the paginated unit via
  prev/next arrows when `bestOf > 1`.
- **End clears the broadcast slot.** Practice runs previously
  stayed stuck in the /live/ "Now Playing" tab after End because
  they never set `matchResult`. They now archive to History
  cleanly, same as versus matches.

## Fixes

- **Signed-in match records lost their `createdBy` stamp** if the
  umpire ended the match while the Firebase auth chunk was still
  loading (fresh page load + quick match). ScoreBoard now
  subscribes to auth on mount, and `finishMatch` awaits a bounded
  hydration window before deciding on the `createdBy` field.
- **SETS column stuck at 0–0** on a genuine draw. Both sides are
  now credited with the decider set on End.

## Migration notes

- **No breaking changes.** All v2.0.x records continue to render
  unchanged. New records carry `createdBy` + `createdByName` fields;
  old ones simply have neither.
- **RTDB rules changed.** `/matches/$id/.write` now permits
  `data.createdBy == auth.uid` as a delete branch, and
  `$id/createdByName` is a new accepted field. **Publish
  `database.rules.json` via Firebase console → Realtime Database →
  Rules** in the same window as the deploy — otherwise self-delete
  fails with `PERMISSION_DENIED` and match archives with
  createdByName get rejected as `$other`.
