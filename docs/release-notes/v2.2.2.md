# Carromscore v2.2.2

Patch release. Two related live-broadcast fixes.

## Fixes

- **Live broadcasts no longer vanish when the umpire's mobile screen
  dims / flickers WiFi / briefly backgrounds.** Firebase's
  `onDisconnect().remove()` was armed at match start to auto-clean
  the `/live/{mid}` record when the WebSocket dropped — a fine
  design for desktop but hostile on mobile browsers, which drop
  WebSockets constantly. Every drop = record deleted server-side =
  the broadcast disappeared from the Lobby even though the umpire
  was still on the match. Removed the onDisconnect wiring
  entirely. Zombie cleanup falls back to the passive 4-hour sweep
  that fires on every admin's `/admin/` visit (already present).
- **Now Playing sheet dialog now updates live.** Opening a card
  from Now Playing to see the full spectator scoreboard used to
  freeze on the snapshot taken at click time — scoring on the
  umpire's phone updated the card in the list but not the open
  sheet. Fixed by resolving the record identifier against the
  current subscription array on every render (same pattern the
  History-tab sheet already used). Now the sheet is a genuine
  live view; digits, BREAK chip, queen coin, everything updates
  in real time.

## Migration notes

- **No RTDB rule changes.**
- **No breaking changes.** Existing records unaffected.
- Zombie `/live/` records from before this build may still show
  up in `/admin/` → Live matches with the "stuck" chip. Sweep as
  normal or wait for the 4h auto-clean.
