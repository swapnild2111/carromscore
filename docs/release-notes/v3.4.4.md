# Carromscore v3.4.4

Solo overlay tracks the umpire's current SET on the phone, plus a
few ScoreBoard header revamps that undo an earlier layout regression.

## What changed

### Solo overlay — active set tracking

- **Overlay renders only the currently-active set**, mirroring the
  umpire's pagination on the phone. When they swipe to SET 2, the
  overlay flips its tile row to that set's data live.
- **New SET header pill** on the outer left of the tile row for
  `bestOf > 1` matches (bo=1 is unchanged): a big DSEG7 digit
  shows the current set number, a small subscript shows the
  bestOf. Reads `SET 2 / 3` at a glance.
- **`practiceSetIdx` is now published on the RTDB `/live/{mid}`
  payload** so remote-broadcast overlays (`/live/?view=overlay`)
  track set changes exactly instead of inferring from cell values.
  Older clients that don't publish it fall back to the previous
  "last non-zero cell" heuristic — no regression.

### ScoreBoard header — revert to compact anchored layout

- **Singles / doubles**: `.head-side-a/b` reverted from
  `justify-self: stretch` (v3.4.2) back to `start / end`. Pills
  hug their content and sit anchored at the outer corners; the
  middle SINGLE-SET / BOARD column no longer gets squeezed by a
  short name pill spanning half the strip.
- **Solo**: the practice-head pill overridden to `flex: 0 0 auto`
  with a `max-width` cap so it hugs the player name. `PRACTICE ·
  1 SET × N BOARDS` meta and `TOTAL MISSED` chip sit centred next
  to it as one visually-grouped header, matching the pre-v3.4.2
  look the umpire preferred.

## Migration notes

- **No RTDB rule changes.** `practiceSetIdx` on the `/live/{mid}`
  payload is a new number field; existing rules already allow any
  number under `liveState`.
- **No schema changes.** No new tournament / match fields.
- **APK bump** (versionCode 51 → 52, versionName 3.4.3 → 3.4.4)
  for TWA parity; wrapper otherwise unchanged.
- **Overlay URLs unchanged.** Both `/score/?view=overlay` and
  `/live/?mid=X&view=overlay` render the new behaviour on the
  next page load.
