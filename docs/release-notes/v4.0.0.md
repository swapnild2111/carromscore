## League format (major new feature)

Full league-format tournament support — groups stage followed by
auto-seeded knockout flights.

**How it works:**

1. Create a tournament with format **League**. Configure group
   count, players per group, boards per group, and flight names
   (e.g. Gold / Silver / Bronze).
2. Open **League Setup** → **Draw** tab. The app distributes
   assigned players into groups using pot-seeding (drag-and-drop
   to adjust). Click **Lock groups & generate schedule** — all
   round-robin group matches are created instantly.
3. Once all group matches are played, open the **Flights** tab.
   Live standings are computed from completed matches. Click
   **Generate flights →** — the app seeds players into Gold,
   Silver, and Bronze knockout brackets automatically.
4. Bracket matches propagate winners between rounds. Print the
   bracket pack for per-board QR stickers.

**Reports for league tournaments:**

- Group standings shown as a compact 2-column grid (one card per
  group with rank, player, W/D/L, boards, points).
- Bracket SVGs per flight showing set-by-set scores.
- Flight order in Reports and Print matches draw order: Groups →
  Gold → Silver → Bronze.

## Tournament format selector redesign

The format picker in **Add tournament** is now a row of four card
tiles — matching the Singles / Doubles / Practice selector on the
home screen. Selected format is highlighted with an amber border.

**"Standard" renamed to "Normal"** — the internal format value
is unchanged (existing tournaments are unaffected); only the
display label changes. All tournament rows now show a format chip
(NORMAL / LEAGUE / KNOCKOUT / ROUND ROBIN).

---

## Knockout & Round Robin — Reports and Print parity

Knockout and Round Robin tournaments now receive the same Reports
and Print treatment as League:

- **Reports → Brackets section**: bracket SVG (QF / SF / Final
  progression) now renders for Knockout and Round Robin tournaments,
  not just League.
- **Reports → Group standings**: Round Robin tournaments now show
  the round-robin group standings grid (same compact layout as
  League group standings), in addition to the bracket section.
- **Print → Schedule**: "Group RR" round in a Round Robin
  tournament now displays as "Round Robin Group" in the schedule
  section.

## Performance improvements

All Firebase reads that previously downloaded full tables are now
scoped to the current tournament via indexed queries.

- **`/planned` reads**: all five read functions in `planned.ts`
  (`loadPlannedByRound`, `loadAllPlannedByRound`, `resolvePlannedByBoard`,
  `propagateBracketWinner`, `loadPendingPlannedByTournament`,
  `subscribePlannedByTournament`) now use
  `orderByChild('tournamentKey')` — only the current tournament's
  records are sent over the WebSocket.
- **`/matches` reads**: Reports tab now loads only the selected
  tournament's matches (indexed query) instead of downloading all
  matches from all tournaments.
- **Print bracket page**: `/planned` and `/matches` are now fetched
  in parallel (single module import, `Promise.all`) instead of
  three sequential async chains. Players no longer block rendering
  — they load reactively after the page is visible.
- **RTDB rules**: `".indexOn": ["tournamentKey"]` added to
  `/matches` node and deployed.

---

## Print bracket improvements

- **Bracket SVGs from match history**: brackets now use `/matches`
  records (with `boardLog` for per-set scores) instead of `/planned`
  data. Shows "3–1", "2–0" etc. in bracket slots.
- **Flight order**: flights in the bracket print match the Reports
  order — Gold first, then Silver, then Bronze (previously
  alphabetical).
- **Schedule section**: sub-rounds (QF - Match 1, QF - Match 2,
  etc.) are merged into one section per stage ("Quarter Finals").
  Round-of-16 and similar rounds labelled generically as "Rounds"
  regardless of player count.

---

## Migration notes

- **RTDB rules publish required** — `/matches` node now requires
  `".indexOn": ["tournamentKey"]`. Publish `database.rules.json`
  via Firebase Console or CLI.
- **No data migration** — all existing tournaments continue to work.
  The "Normal" rename is display-only; `format: 'standard'` is
  unchanged in Firebase.
- **Web-only release** — no APK bump needed.
