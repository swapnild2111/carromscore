# Carromscore v3.4.2

Broadcast overlay overhaul. The transparent `/score/?view=overlay`
strip that OBS / Prism pull as a Browser Source has been redesigned
across singles, doubles, and solo/practice modes after five rounds
of live umpire feedback.

**APK SHA-256**: superseded by v3.4.3 — no APK cut for v3.4.2

<!-- apk-required: false -->

Web changes only — existing v3.4.1 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.
No standalone v3.4.2 APK exists; download the v3.4.3 APK (which
supersedes it) from the GitHub Release page instead.

## What changed

### Overlay layout — all modes

- **Full-width strip.** The overlay strip no longer reserves a
  fixed min-width (was `min(1100px, 94vw)`) — it now sizes to its
  content in the shared `.strip` container, so nothing artificially
  claims horizontal space the umpire wanted for their own branding.
- **Watermark safe-zone padding removed** from `LiveLobby`'s
  `.overlay-wrap`. The old 12rem right-side buffer was for a
  Prism/OBS record indicator; umpires position their branding
  inside the streaming app now, and the reserved band was just
  eating usable overlay width in every mode.
- **First-name-only pills in singles/doubles.** Full display names
  bloated the pills to the point of stacking one character per
  line on 16:9 feeds. Introduced a `firstName()` helper piped
  through `teamLabel()` for the overlay pill only — RTDB, history,
  and scoreboard names untouched.
- **Doubles pill: three-line stack.** `FIRST_A / & / FIRST_B` on
  three centred lines rather than a joined `FIRST_A & FIRST_B`
  string that competed for horizontal budget with the digit.
- **Country note now sits BELOW the name** in every overlay pill
  (was inline). The pill is a flex-column so the country reads
  as a subtitle rather than a competing horizontal chip.

### Solo/practice overlay — full rebuild

- **Every board visible at once.** Replaced the single rolling
  `BOARD n /max` block with one equal-sized tile per configured
  board, plus a TOTAL tile on the right. Matches the production
  `LiveScoreboardView` practice grid the umpires already know.
- **Name pill on its own row above the tiles** rather than
  anchored to the left. Frees the full 96vw for the tile row.
- **Solo pill renders in a single horizontal row** at full player
  name (`VETHANAYAGAM ANTONIO SYLVESTER · Denmark`) — no
  first-name truncation, since the pill has the whole row to
  itself. Singles/doubles pills still stack vertically because
  they compete with the digit for horizontal budget.
- **Digit size adapts to board count.** A CSS `calc()` driven by
  an inline `--tile-count` custom property scales digit font-size
  as `clamp(3.5rem, calc(62vw / --tile-count), 12rem)` — so a
  3-board setup gets ~15vw per digit and a 10-board setup ~5vw,
  both filling the strip cleanly with equal-sized tiles.
- **Current board tile glows in the accent colour** and the TOTAL
  tile is tinted gold, so the two anchor points are visually
  obvious in a broadcast strip.
- **Reads `practiceBoards` + `practiceSetIdx`** from the shared
  localStorage payload published by `ScoreBoard.writeLocalStorage`
  — the overlay now surfaces the umpire's per-board misses live.

### ScoreBoard cleanup

- **OBS button removed** from the ScoreBoard footer. Copying the
  overlay URL was redundant with the existing affordance in
  `LiveLobby`; the button just cluttered the umpire's footer.
- **Header pills stretch to fill their grid cells** so a short
  singles name (`Swapnil`) doesn't leave a wide buffer between
  the pill and the middle SINGLE-SET column. Long names still
  ellipsis-truncate.
- **Solo practice header no longer reserves a phantom right
  column.** Was inheriting the shared 3-column `.head` grid with
  an empty aria-hidden div; switched to a centred flex row.

## Migration notes

- **No RTDB rule changes.** The overlay reads and writes the same
  `/live/{mid}` and localStorage payloads as v3.4.1 (a
  `practiceSetIdx` field was added to the localStorage payload
  but ignored by older clients).
- **No schema changes.** No new tournament / match fields.
- **APK bump** (versionCode 49 → 50, versionName 3.4.1 → 3.4.2)
  for TWA parity; wrapper otherwise unchanged.
- **Live overlay URLs shared before this release still work.** The
  URL shape (`/score/?view=overlay&…`) is unchanged.
