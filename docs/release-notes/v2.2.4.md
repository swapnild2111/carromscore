# Carromscore v2.2.4

Adds a way to support the project. No functional changes to scoring
or gameplay.

## New

- **"Support ❤" link** in the home, Lobby, and admin footers. Opens
  a Ko-fi page (`ko-fi.com/carromscore`) that accepts card, PayPal,
  Apple Pay, and Google Pay. Golden accent — same visual family as
  the version pill and BREAK chip; not a red danger tint.
- **GitHub Sponsor button** on the repo header. Configured via
  `.github/FUNDING.yml`; GitHub renders it automatically. Wires
  both channels — Sponsors + Ko-fi — so viewers pick the one they
  prefer.
- **"Supporting Carromscore" section** on the `/help/` page with the
  full explanation: what donations cover (domain + hosting), and the
  free-forever pledge (no ads, no premium tier, no data sold, nothing
  gated behind money).
- **README badges** for GitHub Sponsors + Ko-fi in the header row,
  plus a "Supporting the project" section under Credits.

## The pledge

Carromscore is a hobby project. It will always stay free. No ads. No
premium tier. No data sold. Donations only cover the domain and
hosting costs, and go directly to the maintainer's account. Nothing
in the app is gated behind money.

## Migration notes

- **No RTDB rule changes.**
- **No breaking changes.** Existing records unaffected.
- Existing installed APKs will start showing the Support link once
  they fetch the latest bundle (usually next app open).
