# Carromscore v2.2.6

Offline-first PWA, resume-match on Home, and fixes for two
scoring/UX bugs. Also fixes an internal CI issue that briefly
blanked production earlier today — no data loss, all match records
intact.

## Fixed

- **Offline app.** After one successful load with internet, the app
  now works fully offline. Precaches every JS/CSS asset the app
  needs so the "half a page" blank-screen after a bad-network
  moment doesn't happen anymore. Match records were already local
  — this release makes the app itself local too.
- **Resume last match.** If you accidentally close the /score/ tab
  mid-match, the home screen now shows a "Resume match" chip so
  you can jump back to the exact URL you closed. No more losing
  the match ID. Clears automatically when the match ends.
- **Phantom row 9 on End at the board cap.** Match records could
  gain an extra board row if the umpire tapped End with stray
  points still on the running board past the board limit. End now
  silently rolls back those points; the winner is decided honestly
  from the completed-boards total.
- **Live cards for practice mode** now show BOARDS x/N + total
  MISSES on the /live/ card so you don't have to open the sheet
  to see progress.

## Added

- **Copy-URL button on every card** in the /live/ lobby (both Now
  Playing and History). Uses a link glyph (🔗). Copies a
  shareable URL — `?mid=<mid>` for live, `?tab=history&match=<id>`
  for history — that opens the same sheet dialog on any device.
- **Deep-link for history archives:**
  `/live/?tab=history&match=<id>` opens a specific match record.

## Migration notes

- **No RTDB rule changes.**
- **First install still needs the internet** (a browser has to
  fetch SOMETHING to install a PWA — that's a hard rule of any
  web app). After that, the app is fully offline.
- Existing users may need to reload once for the new service
  worker to activate. The active SW cleans up old caches on
  first activation.

## Behind the scenes

- **CI safeguard.** The beta preview workflow now builds main from
  source and verifies every JS bundle referenced by the built HTML
  actually exists in the composed artifact before uploading. Fixes
  the incident where a beta build corrupted production.
