# Carromscore v2.1.2

Patch release. Two focused fixes for practice-mode UX after v2.1.1.

## Fixes

- **Practice History cards now show real MISSES + BOARDS.** They were
  stuck at `0 / 0` because the card summary was reading versus-match
  fields (`finalPointsA`, `boardCount`) on practice records — which
  practice never populates. The card now sums `practiceBoards`
  (2D miss matrix) for the grand-total misses and computes
  `sets × boardsPerSet` for total boards. The tap-to-open recap
  popup was already correct — only the card summary was broken.
- **Solo-mode pill in the OBS/Prism overlay no longer dominates.**
  The versus-overlay's `.name` font is 1.5 rem for the compact
  per-side pills — right for versus, top-heavy for solo where the
  pill spans the whole strip. Added a solo-specific override so
  the name reads at `clamp(1rem, 2vw, 1.6rem)` in overlay mode,
  proportional to the board digits below it.

## Not fixed here

- **Blank overlay in Prism Live Studio** after upgrading to v2.1.1
  turned out to be Prism's own Browser Source cache holding an
  older bundle. Right-click the Browser Source → **Refresh cache
  of current page** (or delete + re-add with the same URL) picks
  up the current build. No code change required.

## Migration notes

- **No RTDB rule changes.** Existing rules keep working; no
  republishing required.
- **No breaking record shape changes.** All v2.1.x records render
  unchanged. Practice records written under v2.1.0/2.1.1 will now
  show correct MISSES/BOARDS on the History card automatically —
  the fix is purely on the read side.
