# Carromscore v2.0.0

The biggest release since Carromscore shipped. v2.0 turns the app from
a single-match scoreboard into a full **club-and-tournament platform**:
matches now live in a shared history, spectators can watch live from
any device, and organisers get an admin surface to fix scores and
manage rosters.

Casual anonymous scoring still works exactly like it always did — no
sign-in required to score a match.

## Headlines

- **Live broadcast + spectator URL** — toggle "Live" on setup and share
  a URL. Friends and family watch the score update in real time on any
  phone. Same URL feeds OBS / Prism as a broadcast overlay.
- **Tournament tag on every match** — tag matches with an event name
  (e.g. "Silver Cup 2026"). Matches sharing a tag group together in the
  lobby, collapsible and searchable.
- **Now Playing + History lobby** at `/live/` — one place to see every
  ongoing broadcast and every finished match you've ever played.
- **Firebase-backed player roster** — type a name at setup and it
  autocompletes from a shared roster. Duplicate players ("M. Ilyas" /
  "Ilyas Khan") can be merged by the maintainer.
- **Admin panel** at `/admin/` — Google sign-in, role-based access.
  Super-admin has full CRUD; tournament organisers get inline ✎ edit
  affordances on their event's matches. Audit log tracks every write.
- **Board-by-board recap** — every match now archives the full paper-
  scorecard matrix with per-board coins, queen holder (+Q suffix), and
  cumulative score.
- **Practice mode goes live too** — solo drill sessions broadcast to
  Live URL like versus matches, with a dedicated per-set overlay layout.

## For casual users

Everything still works the same. Score a match, tap End, done.

- **BOARD starts at 0** — matches paper-scorecard convention (Board 1
  is the first row you write, *after* it's finished).
- **Queen guard on BOARD +1 and SET +1** — advance the board only after
  marking who pocketed the queen (or confirming "no queen"). Prevents
  half-scored boards from being archived.
- **Match-end lockout** — after End, positive score inputs freeze so a
  stray tap can't rewrite the archived record. Negatives (POINTS −1
  etc.) remain enabled as undo paths.
- **Live toggle** on setup publishes to Firebase. Toggle it off if you
  want a fully private local match — nothing writes to the cloud.
- **⧉ Share button** in the /live/ lobby's match sheet copies either
  the spectator URL or the OBS overlay URL.

## For organisers

Two new roles:

- **Super-admin** (Carromscore's maintainer) has a full `/admin/`
  surface with Roles, Players, Tournaments, Live cleanup, History
  cleanup, and Audit log tabs.
- **Tournament organiser** (per-tournament role) sees a ✎ pencil on
  every match tagged to their event. Tap to edit scores, correct
  board-log entries, or delete a bad match. Cannot access `/admin/`;
  cannot move a match into a different tournament.

To become an organiser, sign in once at
<https://swapnild2111.github.io/carromscore/> (via the Admin link in
the home footer), then share your Gmail with the super-admin.
Super-admin adds your email in `/admin/` → Roles → and picks which
tournament(s) you organise. See
[docs/admin.md](https://github.com/swapnild2111/carromscore/blob/main/docs/admin.md).

## Technical

- Firebase Auth (Google sign-in) with lazy-loaded chunk — the auth
  bundle is ~35 KB gzipped and never lands on the home page.
- RTDB security rules are the sole enforcement layer. UI gating is UX
  only. Every mutation rule checks role.
- Audit log at `/audit/{pushId}` for every admin write. Append-only,
  super-read only. Forgery-proof (`newData.who == auth.uid`).
- Auto-sweep of stuck /live records >4h old on every super-admin's
  page visit. Cheap batch delete, up to 50 records per pass.
- Email → UID resolution via a client-side `/users/{uid}` mirror
  written on every sign-in (no server-side Admin SDK needed).
- Retention:
  - Tagged versus matches → 1 year
  - Untagged versus matches + practice runs → 3 months

## Migration notes

- **No breaking changes for anonymous users.** Matches recorded on
  v1.x continue to be readable. Anonymous scoring works identically.
- **Live URLs from v1.x are stable.** The `?mid=xxx` share format is
  unchanged.
- **Local storage keys are compatible.** Refreshing mid-match still
  restores state.

## Full changelog

**Admin panel** — Roles/Players/Tournaments/Live cleanup/History
cleanup/Audit log tabs. Email-based organiser invites. Multi-select
bulk actions. Auto-sweep stuck live records. Add-Tournament and
Add-Player buttons.

**Score screen** — BOARD 0-indexed, queen guard on BOARD +1 and
SET +1, match-end lockout, scorecard-matrix recap on End, gold/silver
medal treatment on pills after End.

**Setup screen** — Tournament tag field with autocomplete from prior
tags, Live toggle promoted to hero top-right, two-row footer with
How-to-use / Feedback / Admin links, brighter field labels.

**Lobby** — Now Playing + History tabs grouped by tournament tag,
collapsible, searchable. ✎ pencil on match cards for authorised users
opens the MatchEditModal.

**Overlay** — Cross-device Firebase sync (no longer same-browser only),
tournament tag in header, stronger winner emphasis (gold glow, no loser
dim), country/region visible over camera video, practice-specific
per-set row layout.

**Docs** — Rewritten in-app /help/ page, README, and every feature doc
under docs/features/. New docs/admin.md maintainer guide + docs/admin-
verification.md E2E checklist. Refreshed screenshots throughout.
