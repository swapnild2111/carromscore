# Carromscore v3.4.9

Solo overlay tile treatment fix — the gold "current tile" glow
was misleading (glued to B1 for every practice match) and removed.

**APK SHA-256**: `ed2c8ad0a7a9418aafd765b50c78471b705c76abc18b0c9a95f330ca60ac201e`

Web changes only — existing v3.4.8 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Solo overlay: gold "current tile" highlight removed.** The
  practice/solo tile row no longer glows a specific board tile.
  Previously B1 was permanently highlighted because practice mode
  has no BOARD+1 button — the underlying `board` counter never
  advanced, so the highlight was stuck on the first tile
  regardless of which board the umpire was actually scoring on.
  Umpires flagged it as noise. All B1..Bn tiles now render with
  the same neutral dark-card treatment; the TOTAL tile keeps its
  gold accent border since it's a structurally different tile.
