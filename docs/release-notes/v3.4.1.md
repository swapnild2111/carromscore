# Carromscore v3.4.1

Two bug fixes reported from an anonymous solo (practice) match on
Xiaomi/MIUI: the /live record survived match-end, and the offline
banner stuck after backgrounding.

**APK SHA-256**: `179cac364076f477f782983a1a59042781b9d42041f49a193438a3b9d301e02b`

Web changes only — existing v3.4.0 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Anonymous practice cleanup restored.** v3.3 tightened the
  `/live/{mid}` delete rule to require `auth != null` in every
  branch. That made an anonymous umpire's own record undeletable
  — `endMatch()` on a practice run fired `deleteLive()`, RTDB
  denied it, the client swallowed the error, and the record sat
  in Now Playing until the 4h stale sweep caught it. Fixed by
  adding an anonymous-delete branch guarded on
  `!data.child('createdBy').exists()`. Signed-in records still
  gate on ownership.
- **Console warning on failure.** The practice `endMatch()` now
  logs a warning via `console.warn` if `deleteLive()` fails, so a
  future rule regression surfaces immediately in dev logs rather
  than showing up as a phantom lobby entry days later.
- **Offline banner unsticks on foreground.** Aggressive Android
  OSes (MIUI in particular) suspend background WebSockets. When
  the app returned to foreground, the Firebase SDK's `.info/connected`
  stayed `false` for many seconds before recovering — the banner
  said "You're offline" even with WiFi connected. The ScoreBoard
  already had a `visibilitychange` handler that force-cycled the
  connection on return-from-background, but it was gated on an
  active live-match session. Hoisted the same nudge into
  `BaseLayout` so home + lobby + admin all benefit.

## Migration notes

- **RTDB rules publish required.** The `/live/{mid}` write rule
  changed in `database.rules.json`. Publish it via Firebase console
  → Realtime Database → Rules → paste → Publish. Until the rule
  lands, anonymous practice cleanup will still fail.
- **No schema changes.** No fields added or removed anywhere.
- **APK bump** (versionCode 48 → 49, versionName 3.4.0 → 3.4.1)
  for TWA parity; wrapper otherwise unchanged.
