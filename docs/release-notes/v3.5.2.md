# Carromscore v3.5.2

Patch release. Restores the edit-pencil affordance on the History
tab that was lost when the layout switched from cards to a table
in v3.5.0.

**APK SHA-256**: `9590c4ab637f79228f2fd5306cfe0fa137a2150199bce5b86597a51ace981b86`

<!-- apk-required: false -->

Web changes only — existing v3.5.1 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Edit-pencil restored on History rows**. Each row in the
  History table now shows a small ✎ button in a trailing column,
  gated by the same `canEditMatch()` check the card view used
  (super role, or the tournament's own organiser). Tapping opens
  MatchEditModal exactly like before; clicking anywhere else on
  the row still opens the popup. Reported 2026-08-30 — the
  pencil was on every card in the previous grid view but got
  dropped when v3.5.0 introduced the table.

## Migration notes

- **No RTDB schema changes**, no rule changes.
- **APK bump** (versionCode 61 → 62, versionName 3.5.1 → 3.5.2)
  for TWA parity; wrapper otherwise unchanged.
