# Carromscore v3.5.5

Patch release. Practice / solo matches are now editable through
MatchEditModal — previously the modal opened but showed the
versus-mode fields (sets / points / winner / board log) which
don't apply to practice records.

**APK SHA-256**: `100d47fcd8d6f9bf14ece8bd92fb6a67ce1e670e1567650438181b3a4c2860db`

<!-- apk-required: false -->

Web changes only — existing v3.5.4 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Practice-mode editor** in MatchEditModal. When
  `record.mode === 'practice'`, the versus form is replaced with
  a per-cell miss-count grid — one row per set, one input per
  board within the set, plus a per-row total and a grand total at
  the bottom. The player-name section, notes ("Represents"), and
  tournament tag stay editable. Delete zone stays.
- **`MatchPatch.practiceBoards`** field added. `applyMatchPatch`
  sanitises the incoming 2D matrix (coerces cells to non-negative
  integers, caps dimensions at 20x20) before merging into the
  record.

## Migration notes

- **No RTDB rule change** — the existing `/matches/$id`
  `.validate` accepts `practiceBoards` as a bag-shaped node with
  no strict schema.
- **APK bump** (versionCode 64 → 65, versionName 3.5.4 → 3.5.5)
  for TWA parity; wrapper otherwise unchanged.
