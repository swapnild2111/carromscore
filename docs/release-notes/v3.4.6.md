# Carromscore v3.4.6

Solo overlay tile polish — digits shrink ~20% and tile background
goes near-opaque so a broadcast strip reads cleanly over the carrom
table's wood grain.

Web changes only — existing v3.4.5 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Solo tile digits reduced ~20%.** Clamp goes from
  `clamp(3.5rem, calc(62vw / --tile-count), 12rem)` to
  `clamp(2.8rem, calc(50vw / --tile-count), 9.5rem)`. On live
  camera feeds (tested with Prism Live at 1080p) the old size
  fought the carrom board for attention — the smaller clamp
  keeps digits legible without dominating the frame.
- **Tile background near-opaque.** `rgba(15,15,15,0.72)` →
  `rgba(0,0,0,0.9)` plus an 8px backdrop-blur. Was semi-
  transparent enough that wood-grain on the table bled through
  each tile and made the digit look ghosted; now reads as a real
  dark card.

## Migration notes

- **No RTDB rule changes**, no schema changes.
- **APK bump** (versionCode 53 → 54, versionName 3.4.5 → 3.4.6)
  for TWA parity; wrapper otherwise unchanged.
- Existing `/live/?view=overlay` and `/score/?view=overlay` URLs
  render the tweaks automatically on next page load.
