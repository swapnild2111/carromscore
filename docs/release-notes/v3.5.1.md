# Carromscore v3.5.1

Patch release. Two related fixes for the tied-set flow reported
right after v3.5.0 landed.

**APK SHA-256**: `f9832dda3e0d3181ad57676e2cdda411ec0092824aebc0ed0850c027a5e24688`

<!-- apk-required: false -->

Web changes only — existing v3.5.0 APK installs auto-update on
next launch. TWA bumped for parity; fresh APK download is optional.

## What changed

- **Drawn set in a bo3+ no longer ends the whole match.**
  Previously choosing "Commit as draw" from the tie-at-cap
  chooser archived the match immediately. In a multi-set format
  that skipped everything after set 1. Now: if bestOf isn't
  exhausted and neither side has clinched, the drawn set is
  recorded and the match rolls into the next set — points reset,
  board reset, queen cleared, break flipped, decider cap
  restored, and the swap-sides prompt appears. Only the last
  drawable set (or a truly-exhausted multi-set with every set
  drawn) archives from the chooser.
- **Drawn sets get a positional slot in `setWinners`.** The
  ordered credit log is now `Array<'a' | 'b' | 'draw'>` so later
  sets stay lined up with the array's indices after a mid-match
  draw. Consumers treat `'draw'` slots as no-credit (falls back
  to boardLog totals — which for a tied set produces a
  no-winner ribbon).
- **Better toast copy for tied-below-cap SET+**. The old *"Set
  is tied — tap End Match to play a deciding board"* was
  misleading (End is match-terminating; a below-cap tie just
  needs another board). New copy: *"Score is tied — play
  another board to break the tie."* The tie-at-cap flow
  continues to open the decider chooser directly.

## Migration notes

- **RTDB rule update** on `/matches/{id}/setWinners/$idx` — now
  accepts `'draw'` in addition to `'a'` and `'b'`. Requires a
  manual publish in Firebase Console before new writes with a
  drawn-set slot will land.
- **No schema break** — the extra `'draw'` value is additive.
  Records without drawn sets read identically to v3.5.0.
- **APK bump** (versionCode 60 → 61, versionName 3.5.0 → 3.5.1)
  for TWA parity; wrapper otherwise unchanged.
